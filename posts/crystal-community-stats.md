# Crystal Community Stats: A Dashboard for the Ecosystem

April 27, 2026

There's a new way to see how Crystal is growing.

Serdar Doğruyol just launched Crystal Community Stats — a dashboard that tracks Crystal projects on GitHub. You can see total repositories, 30-day trends to see what's gaining momentum, contributor data, and star trends.

Why this matters.

Before this, if you wanted to know how the ecosystem was doing, you had to guess. Or dig through GitHub searches. Or just rely on vibes. Now there's actual data.

Some things the dashboard shows:

- How many Crystal repos exist (almost 10,000)
- Which projects are active right now
- Where stars are clustering

This is useful for developers looking for active projects to contribute to. It's also useful for anyone who just wants to see that Crystal isn't dead — it's growing.

The dashboard is live at crystalcommunity.org/stats.

Check it out. And if you're building something in Crystal, your project is probably in there.
